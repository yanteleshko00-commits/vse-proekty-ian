# NEXORA Image — подключение генерации

Страница генератора: `/image`.

## Модель

Cloudflare Workers AI, модель `@cf/black-forest-labs/flux-2-klein-4b`. Она поддерживает генерацию по тексту и редактирование на основе референсного изображения.

## Что добавить в Render

Откройте сервис **nexora-lobby** → **Environment** и добавьте две переменные:

- `CLOUDFLARE_ACCOUNT_ID` — Account ID из панели Cloudflare.
- `CLOUDFLARE_API_TOKEN` — API Token с разрешением **Account → Workers AI → Read** для нужного аккаунта.

Не добавляйте токен в GitHub, HTML или браузер. Сохраняйте его только как секретную переменную Render.

После сохранения Render перезапустит сервис. Проверить настройку можно по адресу `/health`: поле `imageGeneratorConfigured` должно стать `true`.

## Бесплатная квота

Workers AI включает 10 000 Neurons в сутки на бесплатном плане. Квота общая для аккаунта и сбрасывается ежедневно. После исчерпания бесплатной квоты генерация остановится до сброса; NEXORA не включает платную оплату автоматически.
