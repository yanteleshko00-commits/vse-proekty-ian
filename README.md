# Все проекты #Ian — версия 3.0

Обновлённый генератор школьных проектов.

Что изменено:
- презентация больше не состоит из пустых белых слайдов;
- ИИ формирует отдельную визуальную концепцию проекта;
- до 6 тематических иллюстраций генерируются через OpenAI Images API;
- добавлены несколько макетов слайдов: split, cards, full-image;
- цветовая палитра подбирается под тему;
- при сбое генерации изображения используется полноценная векторная иллюстрация, а не пустая заглушка;
- файл требований школы (.pdf/.docx) теперь отправляется на сервер и учитывается при генерации;
- PDF-презентация остаётся ровно нужной длины и не добавляет пустые страницы.

## Запуск
1. `npm install`
2. Создай `.env` на основе `.env.example`.
3. Укажи `OPENAI_API_KEY`.
4. `npm start`

Для Render добавь Environment Variables:
- `OPENAI_API_KEY` — твой ключ
- `OPENAI_MODEL` — `gpt-6-luna`
- `OPENAI_IMAGE_MODEL` — `gpt-image-1`

Не публикуй API-ключ в GitHub или в `index.html`.
