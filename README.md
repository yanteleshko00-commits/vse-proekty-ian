# Все проекты #Ian — ИИ-генератор

## Что умеет

Кнопка «Создать проект» отправляет данные формы на сервер, сервер вызывает OpenAI Responses API и после генерации создаёт настоящие файлы:

- `Индивидуальный_проект.docx` — Word
- `Презентация_проекта.pdf` — PDF
- `Текст_защиты.pdf` — PDF
- `Буклет.pdf` — PDF
- `Весь_проект.zip` — архив со всеми файлами

API-ключ находится только на сервере в `.env`, а не в `index.html`.

## Запуск

Требуется Node.js 20+ и действующий OpenAI API key.

1. Распакуйте архив.
2. В папке проекта выполните `npm install`.
3. Создайте файл `.env` на основе `.env.example`.
4. В `.env` укажите `OPENAI_API_KEY`.
5. Запустите `npm start`.
6. Откройте `http://localhost:3000`.

## Важно

API платный: стоимость зависит от выбранной модели и объёма токенов. Не публикуйте `.env` и API key в GitHub или внутри сайта.

Требования конкретной школы могут отличаться, поэтому автоматически созданный проект нужно проверить перед сдачей.
