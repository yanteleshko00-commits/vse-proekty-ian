📱 Как добавить сайт на телефон?

Из чего состоит индивидуальный проект?

1. 📄 Текстовая часть

Введение, теоретическая часть, практическая часть, заключение и источники.

2. 🎯 Проектный продукт

Буклет, памятка, инструкция, чек-лист, анкета, карточки и другие варианты.

3. 📊 Презентация

Актуальность, цель, задачи, основные идеи, практика, продукт и выводы.

4. 🎙️ Защита

Готовый текст выступления и ответы на возможные вопросы.

📱 Добавить сайт на телефон

🍎 iPhone

1. Открой сайт в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран Домой».
4. Нажми «Добавить».

🤖 Android

1. Открой сайт в Chrome.
2. Нажми «⋮».
3. Выбери «Добавить на главный экран».
4. Подтверди.
