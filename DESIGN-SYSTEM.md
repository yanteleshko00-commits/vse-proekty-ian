# NEXORA design v3

Visual direction: curated hero sections (Supahero), readable package comparisons (Pricing Pages), clear navigation (Navbar Gallery), one focused primary action (CTA Gallery), useful footer links (Footer Design). These are inspiration sources, not copied templates.

The visual layer preserves existing IDs, forms, endpoints, pricing data and generated-content logic. Shared spacing, radii, focus rings, accent, typography and reduced-motion rules are embedded in each independently deployed service to avoid a cross-service CSS dependency. The project site serves its stylesheet locally. Preserve explicit dark theme behavior and test the mobile viewport at 390px before release.
